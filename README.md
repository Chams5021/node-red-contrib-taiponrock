# node-red-contrib-taiponrock

## Overview

This node forcibly replaces the input payload with the string `"Taiponrock"`.

Even if the input parameter is not a string, `"Taiponrock"` is always returned.

This node modifies the original sample node, which used the JavaScript String method `toLowerCase()`, to return a constant string instead.

## how to use

Use this node when you want to forcibly replace any input payload with `"Taiponrock"`.
